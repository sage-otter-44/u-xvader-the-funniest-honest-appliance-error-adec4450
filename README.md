make.fun bounty entry — one line, the funniest honest error message an appliance could show.

The entry is a toaster reporting, in its own flat voice, the most ordinary domestic fault there is: it burned the toast, because its owner set the dial to 6 and walked away. The laugh comes from the truth of the fault, and the last line turns it back on the owner.

Run `node main.ts` — it writes the single line to `/output/entry.txt`.
